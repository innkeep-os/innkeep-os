# journal/

Dated logs, `YYYY-MM-DD.md`, append-only.

**Written for Claude, not for you.** Dense detail is good here — it is the
cross-session memory, and the place superseded material goes so that project
docs can stay current-state only.

`letters/` holds the letters: once a day, a session reads the workspace and
writes a page about it. Innkeep renders those and nothing else in the app is
allowed to offer a judgment.
