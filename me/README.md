# me/ — the model of you

Three files, all short by design. Claude reads them before acting, and Innkeep
shows all three on one page.

- **profile.md** — who you are. Facts you have stated.
- **preferences.md** — how you like things done, and why. Mostly earned by
  correcting something.
- **learnings.md** — observations seen once, not yet believed. A second
  sighting promotes one into the files above and deletes it from here.
